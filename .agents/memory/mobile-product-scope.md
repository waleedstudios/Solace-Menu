---
name: Mobile product scope
description: Audience and boundaries for the SolaceMenu native companion
---

The iPhone app serves both restaurant owners/staff and customers, alongside—not instead of—the website. Customers can browse public menus without an account. Restaurant tools share the website's actual data and nutrition/cost calculations.

**Why:** The user explicitly selected both audiences when asking for an App Store-publishable app.

**How to apply:** Keep a guest customer path and an authenticated business path. Do not create a disconnected demo database or replace the website with the mobile app. Clearly distinguish an app that is ready to preview from one that has passed native device testing and Apple review.
